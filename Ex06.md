1. pre-push checklist

- kiểm tra mã nguồn trước khi đẩy lên github
- tìm và loại bỏ api keys, passwords, tokens bị hardcode
- sử dụng gitleaks để quét thông tin bí mật
- kiểm tra file .env đã được thêm vào .gitignore
- kiểm tra lại bằng lệnh git status

2. hướng dẫn bật 2fa

- vào github settings
- chọn password and authentication
- chọn enable two-factor authentication
- sử dụng ứng dụng xác thực hoặc security key
- yêu cầu tất cả thành viên tham gia repository bật 2fa

báo cáo rủi ro nếu thiếu .gitignore:

- file .env có thể bị đưa lên github public
- api keys và mật khẩu có thể bị lộ
- người khác có thể sử dụng thông tin bị lộ để truy cập hệ thống
